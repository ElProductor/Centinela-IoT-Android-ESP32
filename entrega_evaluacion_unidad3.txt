4. MATRIZ DE CUMPLIMIENTO DE CRITERIOS DE EVALUACIÓN (UNIDAD 3)
================================================================================

[CRITERIO 3.1.1] Codificación de instrucciones siguiendo estándar de información segura:
- Comunicación cifrada HTTPS/TLS mediante WiFiClientSecure (ESP32) y OkHttp3 (Android).
- Cabeceras obligatorias 'apikey' y 'Authorization: Bearer <JWT>' hacia Supabase Cloud.
- Sentencias SQL preparadas (Prepared Statements con prepare y bind_param) en la API local
  PHP (api/guardar_datos.php) para eliminar vulnerabilidades de Inyección SQL (SQLi).
- Hashing criptográfico de contraseñas con SHA-256 + Salt único y resguardo en NVS (Preferences.h).

[CRITERIO 3.1.2] Programación de comunicación Serial bajo programación segura:
- Analizador sintáctico no bloqueante atenderPuertoSerialNoBloqueante() con buffer estático
  acotado a 256 bytes (MAX_SERIAL_FRAME_LEN) para prevenir ataques de desbordamiento de búfer.
- Estructura de trama delimitada por caracteres binarios: <STX>CMD|PARAMS|FIRMA<ETX> (\x02 y \x03).
- Verificación obligatoria de firma HMAC-SHA256 (truncada a 16 hex) antes de ejecutar cualquier
  instrucción hacia sensores o actuadores (GET_SENSORS, SET_THRESHOLDS, ACTUATOR_CTRL).
- Handshake de prueba bidireccional Mobile-MCU: CMD_PING_HANDSHAKE -> ACK_PONG_READY.

[CRITERIO 3.1.3] Control inalámbrico de microcontrolador en envío y recepción de instrucciones:
- Servidor web asíncrono embebido en ESP32 sirviendo endpoints REST (/lecturas y /api/v1/control).
- Portal de diagnóstico en PROGMEM con login autenticado y comandos remotos para liberar pestillo (90°)
  o forzar bloqueo (0°), además de calibración de umbrales en caliente (10 a 200 cm).
- Integración del sensor termohigrométrico digital DHT11 en GPIO 27 correlacionado con proximidad
  ultrasónica (HC-SR04 en GPIO 5/18) e iluminación (LDR GL5528 en GPIO 34).
- Desacoplamiento electromecánico del servomotor SG90 (GPIO 13) y zumbador PWM a 2 kHz (GPIO 14).

[CRITERIO 3.1.4] Conexión segura App Android - IoT bajo estándar ISO/IEC 27000:
- Enrutador de transporte polimórfico (CentinelaSmartDeviceController) con tres vías conmutables:
  Wi-Fi Local REST, Supabase Cloud HTTPS y Serial Seguro USB-OTG a 115200 baudios.
- Algoritmo de Reconexión Automática con Retroceso Exponencial y Variación Aleatoria
  (Exponential Backoff with Jitter: T_wait = min(T_max, T_base * 2^k) + U(0, J_max)).
- Arquitectura de Almacenamiento Temporal Store-and-Forward: Cola offline persistente en LittleFS
  (/offline_queue.jsonl, 64 KB / 512 registros) en el ESP32 y SQLite Room en Android, garantizando
  cero pérdida de datos ante caídas de red Wi-Fi o internet.
- Modo Modem-Sleep dinámico (WiFi.setSleep(true)), reduciendo el consumo energético de 195 mA a 68 mA.

5. ESQUEMA DE PINES Y CONEXIONES FÍSICAS (ESP32-WROOM-32)
================================================================================

- GPIO 5  (D5)  -> Trigger del Sensor Ultrasónico HC-SR04
- GPIO 18 (D18) -> Echo del HC-SR04 (Divisor resistivo 1k / 2k -> 3.33V seguro)
- GPIO 34 (D34) -> Fotorresistencia LDR GL5528 (Divisor con R 10k a GND, canal ADC1_CH6)
- GPIO 27 (D27) -> Sensor Termohigrométrico Digital DHT11 (Pull-up 4.7k a 3.3V)
- GPIO 13 (D13) -> Servomotor SG90 (Pestillo Perimetral - Canal PWM 50 Hz)
- GPIO 14 (D14) -> Zumbador Piezoeléctrico Pasivo (Alarma 2000 Hz, canal LEDC 0)
- GPIO 4  (D4)  -> Pulsador Físico de Desarme (INPUT_PULLUP a GND con debounce 50 ms)
- VIN / 5V      -> Alimentación 5V para HC-SR04 y Servomotor SG90
- 3V3           -> Alimentación 3.3V para LDR GL5528 y DHT11
- GND           -> Tierra común compartida
